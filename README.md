# Alex Monroe — Video Editor & VFX Compositor Portfolio

A premium, Apple-inspired portfolio website for a professional Video Editor, Short Form Editor, Long Form Editor, and VFX Compositor.

## Key Technologies

- **TanStack Start** (React 19, file-based routing)
- **Framer Motion** — cinematic scroll reveals, page transitions, modal animations
- **TailwindCSS v4** — utility-first styling
- **Custom CSS** — glassmorphism, ambient glows, smooth cursor, typography
- **Netlify** — hosting and deployment

## Features

- Cinematic loading screen with progress animation
- Custom cursor with follower effect
- Fullscreen hero with floating particle canvas and ambient lights
- Scroll-triggered reveal animations across all sections
- Portfolio grid with category filtering and video modal
- Interactive showreel player with cinematic styling
- Services section with glassmorphism hover cards
- Testimonial slider with fade transitions
- Contact form with WhatsApp, Email, and Calendly CTAs
- Apple-style minimal footer

## Running Locally

```bash
npm install
npm run dev
# Opens on http://localhost:3000
```

Requires Node 18+.
